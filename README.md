# AgenticAI-ADLC
Securing AI agents across every phase of the development lifecycle.
AI agents don’t just generate text anymore. They read untrusted content, call tools, access real data, and take actions on their own. Traditional SDLC security practices weren’t built for systems that are non-deterministic and can be steered by a cleverly worded email or web page.

The ADLC adapts the secure development lifecycle for agentic AI. It covers each phase from scoping and threat modeling through design, build, testing, deployment, and monitoring, with agent-specific controls like least-privilege tool access, human approval for high-impact actions, prompt injection testing, and CI-gated security evals.

This repo is hands-on: each phase includes templates, policies, and working examples, built around a sample agent that’s shown first in a vulnerable state and then hardened.
